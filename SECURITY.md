# Security policy

## Reporting a vulnerability

Do not publish passwords, personal data, exploit details, or screenshots containing sensitive information in a public issue.

If the repository's **Security** tab offers **Report a vulnerability**, use that private channel. Otherwise, email `v_marchiori@itcslazzari.eu` with the subject `Segnalazione sicurezza Museo Sabbie` and ask to continue through a private channel. Do not include working exploits, passwords, tokens, or personal data in the first message.

Include the affected page, the browser used, steps to reproduce the issue, its possible impact, and a safe proof of concept when available.

The maintainers will review reports as soon as possible and publish a fix before disclosing technical details.

## Supported version

Only the current version published from the `main` branch is supported.
